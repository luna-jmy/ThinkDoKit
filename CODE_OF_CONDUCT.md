# Code of Conduct

## Our Standard

We want ThinkDoKit to be a friendly and practical project space. Please be respectful, constructive, and considerate in issues, pull requests, and other project discussions.

Examples of positive behavior include:

- Giving actionable and respectful feedback
- Assuming good intent while still being clear about problems
- Focusing on improving the project rather than winning arguments

Examples of unacceptable behavior include:

- Personal attacks or harassment
- Discriminatory or insulting language
- Repeatedly derailing discussions
- Publishing private information without permission

## Enforcement

Project maintainers may moderate, edit, or remove comments and contributions that do not align with this code of conduct.

## Reporting

For behavior concerns, please open a private security-style report if possible, or contact the maintainer through the repository owner account.
