# Security Policy

## Reporting a Vulnerability

If you find a security issue in this repository, please avoid opening a public issue with sensitive details.

Instead, contact the maintainer privately through GitHub first and include:

- A short description of the issue
- Steps to reproduce
- Impact assessment
- Any suggested fix or mitigation

## Scope

Security issues may include:

- Malicious or unsafe scripts included in distributed assets
- Sensitive data accidentally committed to the repository
- Packaging behavior that leaks local or unintended files into release archives

## Response

The project aims to acknowledge reports promptly and fix confirmed issues in a future release.
