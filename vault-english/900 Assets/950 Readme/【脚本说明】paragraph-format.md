# 段落格式化脚本

> _脚本名称：paragraph-format.js_
> _位置：vault/900 Assets/960 Scripts/_
> _类型：QuickAdd 脚本_

---

## 功能概述

这是一个强大的段落格式化 QuickAdd 脚本，用于批量处理 Obsidian 笔记中的空行和段落格式。

---

## 核心功能

### 1. 批量插入空行

**功能：** 在段落之间自动插入空行，提高可读性

**规则：**
- 段落之间插入空行
- 连续的列表项之间不插入
- 连续的表格行之间不插入
- 连续的 callout 内容之间不插入
- 代码块中不插入空行
- 以两个空格结尾的行（手动换行）不插入空行

**适用场景：**
- 书摘格式化
- 长文档编辑
- 提高笔记可读性

---

### 2. 批量删除空行

**功能：** 删除所有空行，压缩内容

**适用场景：**
- 清理过度留白的笔记
- 准备进行段落规整

---

### 3. 段落规整

**功能：** 智能段落格式化，根据上下文决定是否插入空行

**智能判断：**
- **列表项**（`- `、`* `、`1. `、`+ `）之间：不插入空行
- **表格行**（包含 `|`）之间：不插入空行
- **Callout 块**（`[!note]-` 等）之间：不插入空行
- **Callout 内容**（以 `>` 开头）之间：不插入空行
- **项目进度项**（`- [xxx::]`）之间：不插入空行
- **Button 标签**（`` `button-xxx` ``）周围：不插入空行
- **代码块**（```）内部：不插入空行
- **手动换行**（以两个空格结尾）：不插入空行
- **分隔符**（`---`、`***`、`___`）周围：需要空行
- **表格块边界**：需要空行
- **Callout 块边界**：需要空行
- **其他情况**：需要空行

**适用场景：**
- 统一笔记格式
- 书摘整理
- 文档规范化

### YAML Header

```yaml

```

脚本会识别并保留 YAML header，只处理正文内容。

## 使用方法

### 方法 1：QuickAdd 命令

1. 在 Obsidian 中打开需要处理的笔记
2. 按 `Ctrl + P`（或 `Cmd + P`）
3. 输入：`paragraph-format`
4. 运行命令
5. 选择操作：
   - **批量插入空行** - 在段落之间添加空行
   - **批量删除空行** - 删除所有空行
   - **段落规整** - 智能段落格式化

---

### 方法 2：配置为 QuickAdd 宏

1. 打开 QuickAdd 插件设置
2. 创建新宏或选择器
3. 添加此脚本：`paragraph-format.js`
4. 配置为命令或快捷键

```markdown

书摘 2
```

**说明：** 表格行保持紧凑，表格前后有空行。

## 注意事项

1. **YAML Header** - 会被保留，只处理正文内容
2. **代码块** - 内部不插入空行，保持代码格式
3. **手动换行** - 以两个空格结尾的行不插入空行
4. **分隔符** - 周围需要空行
5. **边界情况** - 进入/离开表格、Callout 等块时需要空行
