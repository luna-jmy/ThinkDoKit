# MonthlyArchive.js 说明文档

脚本文件：[[MonthlyArchive.js]]

## 功能概述

MonthlyArchive.js 是一个用于 Obsidian 的 QuickAdd 自定义脚本，主要功能是将指定日期范围内的每日日志内容归档到一个笔记中。该脚本可以灵活选择日期范围，提取并整理指定时间段内的日志内容，支持多种插入方式。

## 主要功能

1. **日期范围选择**：
   - 支持通过输入开始和结束日期来选择日期范围
   - 支持选择特定月份进行归档
   - 自动验证日期格式和有效性

2. **内容提取与处理**：
   - 自动从指定路径（`500 Journal/540 Daily/`）查找每日日志文件
   - 提取并处理日志内容，包括：
     - 移除 frontmatter
     - 移除备注内容（%%备注%%）
     - 移除代码块
     - 移除 callouts
     - 移除特定格式的内容
     - 增加标题层级
     - 压缩空行
   - 处理 DataviewJS 表达式，自动获取前一天日志中的"明天想改进的事"字段

3. **内容插入方式**：
   - 在光标位置插入
   - 在文件末尾追加
   - 复制到剪贴板

## 使用方法

1. 确保已安装 QuickAdd 插件
2. 将此脚本添加到 QuickAdd 的用户脚本中
3. 创建一个 QuickAdd 宏，选择此脚本
4. 运行宏，按照提示操作

## 使用流程

1. 运行脚本后，首先选择日期范围方式：
   - 📅 选择日期范围：输入开始和结束日期 (YYYY-MM-DD)
   - 📆 选择特定月份：输入月份 (YYYY-MM)

2. 根据选择输入相应的日期信息

3. 选择内容插入方式：
   - 📍 光标位置插入：在当前光标位置插入归档内容
   - 📄 文件末尾追加：在文件末尾添加归档内容
   - 📋 复制到剪贴板：将归档内容复制到剪贴板，不修改文件

4. 脚本会自动处理并生成归档内容

## 输出格式

归档内容的基本格式如下：

```markdown
## 🗄️ 日期范围归档 (YYYY-MM-DD 至 YYYY-MM-DD)

### 周X YYYY-MM-DD
[当日日志内容，已处理]

---

### 周X YYYY-MM-DD
[当日日志内容，已处理]

---

> 已归档 X/X 天日志 | 归档范围: XXXX年XX月-XXXX年XX月
```

## 依赖项

- Obsidian 应用
- QuickAdd 插件
- Moment.js（用于日期处理）

## 注意事项

1. 脚本假设每日日志存储在 `500 Journal/540 Daily/` 路径下，文件名为 `YYYY-MM-DD.md`
2. 脚本会自动处理并清理日志内容，移除不必要的部分
3. 如果找不到某一天的日志，会显示"（无当日日志）"
4. 脚本会自动处理前一天日志中的"明天想改进的事"字段，并替换 DataviewJS 表达式

## 错误处理

脚本包含以下错误处理机制：
- 检查是否有活跃文件
- 验证日期格式和有效性
- 处理文件读取错误
- 处理 DataviewJS 表达式解析错误

## 自定义选项

如需自定义脚本，可以修改以下部分：
- 每日日志的存储路径
- 内容过滤规则
- 输出格式
- 日期格式
