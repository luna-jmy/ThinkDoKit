## macOS 截图快捷键速查表（官方默认）

**符号说明**：⌘ = Command | ⇧ = Shift | ⌥ = Option | ␣ = 空格

---

### 🖥️ 基础截图（最常用）

| 快捷键组合 | 功能 | 操作细节 |
|------------|------|----------|
| **⇧⌘3** | 截取**整个屏幕**（多显示器会各截一张） | 自动保存至桌面；角落出现缩略图可点按编辑，或等待自动保存 |
| **⇧⌘4** | 截取**选定区域** | 鼠标拖选范围；松开即完成捕获 |
| **⇧⌘4 + ␣** | 截取**单个窗口/菜单** | 指针变相机，点选目标窗口/菜单；按␣可切换“窗口/区域”模式 |
| **⇧⌘5** | 打开**截屏控制中心**（macOS 10.14+） | 底部出现工具栏，支持全屏/窗口/区域截图、录屏，可设置延时、存储位置等 |

---

### 📱 特殊场景截图

| 快捷键组合 | 功能 | 适用设备 |
|------------|------|----------|
| **⇧⌘6** | 截取**触控栏** | 带触控栏的 MacBook Pro 专用 |
| **⇧⌘5 → 选项 → 计时器** | **延时截图** | 可选 5 秒/10 秒，适合准备右键菜单、通知中心等瞬态界面 |

### ⚙️ 进阶技巧（高效自定义）

#### 1. 直接复制到剪贴板（不存文件）

在任意截图快捷键前加 **⌃**（Control），例如：

- **⌃⇧⌘3**：全屏截图→剪贴板
- **⌃⇧⌘4**：区域截图→剪贴板
- 粘贴到微信、VS Code、预览等应用即可

#### 2. 修改默认保存位置

- 方法1（图形化，推荐）：**⇧⌘5 → 选项 → 存储到**，选择桌面/图片/文稿或自定义文件夹
- 方法2（终端命令）：
  ```bash
  defaults write com.apple.screencapture location ~/Pictures/Screenshots  # 自定义路径
  killall SystemUIServer  # 生效
  ```
#### 3. 截图编辑

- 截图后**角落缩略图**：点按即可进入预览编辑，支持标注、裁剪、形状、文字
- 已保存截图：双击用**预览（Preview）**打开，顶部“标记”工具栏可编辑

---

### 📌 通用规则

- **文件格式**：默认 PNG，含日期时间，命名如“截图 2026-03-09 20.30.15”
- **编辑入口**：缩略图点击/双击预览文件均可编辑
- **取消截图**：按下 **Esc** 键退出捕获模式
