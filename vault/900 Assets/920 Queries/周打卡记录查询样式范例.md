**方案1：使用 LIST 显示（推荐）**
```dataview
LIST WITHOUT ID
	"**" + file.name + "**  " + 
	"🧠闪卡" + 🧠flashcard + " " + 
	"💊吃药" + 💊medicine + " " + 
	"⚖️体重" + weight⚖️ + " " + 
	"🏃运动" + exercise🕓 + " " + 
	"📖月度" + reading🕓 + " " + 
	"💰存款" + saving💰 + " " + 
	"💸花销" + spent💰 + " " + 
	"🧘‍♂️冥想" + meditation🧮
FROM "500 Journal/540 Daily"
WHERE date(file.name) >= this.journal-date 
	AND date(file.name) <= date(this.journal-date + dur(6 days))
SORT file.name ASC
```
