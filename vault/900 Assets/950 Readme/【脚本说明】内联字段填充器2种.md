内联字段是dataview插件特有的格式，可以在笔记正文的任意位置插入，功能类似于YAML header中的元数据（笔记属性），但仅在dataview中生效。也就是说，通过内联字段创建的属性可用于dataview查询，但无法在Obsidian原生查询和搜索中使用。

通常我不推荐使用内联字段，但日志打卡这类场景例外。虽然完全使用笔记属性也能实现同样功能，但这些属性通常不需要跨文件夹调用，数量较多时会导致属性栏臃肿难管理。因此，我会将非通用属性（如日志打卡、GTD任务管理等）存放在笔记的内联字段中。

另外一种场景是动态图表，我会把图表的一些参数放在内联字段里，这样就不用修改代码，在阅读模式下也可以调整关键参数修改图表。比如主页用到的的：[[生命之轮]]

内联字段是纯文本格式的，填写体验不如笔记属性，因此做了这样一个小改良，也方便在手机版和阅读模式下更新笔记。

脚本的具体特性、使用方法、示例和效果如下：

## 脚本1：习惯打卡

### 主要特性：

1. **识别空内联字段**：使用正则表达式 `/\[([^:\]]+)::\]/g` 匹配所有 `[字段名::]` 格式的空字段
2. **按顺序弹出输入框**：根据字段在文档中出现的顺序，逐个弹出输入提示框
3. **支持跳过**：用户可以留空或点击取消来跳过某个字段
4. **批量处理**：一次性处理文档中的所有空字段
5. **预设打卡选项**：预设了medicine, flashcard, meditation, fasting四个字段。如需修改，需要在源代码中调整。

### 使用方法：

1. 将代码`MetadataInputPrompt.js`保存到笔记库任意文件夹（公众号消息栏输入“字段填充”获取代码下载链接）
2. 在 Obsidian 中安装 QuickAdd 插件
3. 在QuickAdd插件中添加新的宏，选择刚刚保存的脚本文件
4. 在包含任务的笔记中运行宏
5. 在有空内联字段的笔记中运行这个宏

### 注意事项
- 内联字段必须用用 `[]` 括起来，只使用双冒号 `::` 不会被识别为需要输入内容的内联字段

### 示例文本

```
#### 打卡(✅❎🔲) 
- [💊medicine::] 
- [🧠flashcard::] 
- [🧘meditation::] 
- [🍽️fasting::]  

#### 数据(填写数值) 
- [weight⚖️::] 
- [exercise🕓::] 
- [reading🕓::] 
- [saving💰::] 
- [spent💰::]
```

### Dataview周汇总效果
打卡数据可以在周日志或月日志中进行汇总，自动生成打卡数据一览。数值数据还可以通过Charts插件生成动态数据图表。

![[Pasted image 20250705112725.png]]

Dataview周打卡查询代码：

````
```dataview
TABLE WITHOUT ID
	file.name as "📅",
	🧠flashcard as "🧠✅",
	💊medicine as "💊✅",
	🧘‍♂️meditation as "🧘‍♂️✅",
	🍽️fasting as "🍽️✅",
	weight⚖️ as "⚖️⚖️",
	exercise🕓 as "🏃🕓",
	reading🕓 as "📖🕓"
FROM "500 Journal/540 Daily"
WHERE date(file.name) >= this.journal-date 
	AND date(file.name) <= date(dateformat(date(this.journal-date + dur(6 days)), "yyyy-MM-dd"))
SORT file.name ASC
```
````

## 脚本2：内联字段更新

### 主要特性：

1. **既可输入也可修改**：检测所有内联字段（无论是否为空），允许修改已有值
2. **字段选择界面**：显示所有字段及其当前状态，让用户选择要处理的字段
3. **批量处理选项**：可以选择"处理所有字段"或单独处理某个字段
4. **当前值显示**：在输入时显示字段的当前值作为参考

### 使用方法：

1. 将代码`MetadataUpdatePrompt.js`保存到笔记库任意文件夹（公众号消息栏输入“字段填充”获取代码下载链接）
2. 在 Obsidian 中安装 QuickAdd 插件
3. 在QuickAdd插件中添加新的宏，选择刚刚保存的脚本文件
4. 在包含任务的笔记中运行宏
5. 在有空内联字段的笔记中运行这个宏
