## 使用方法

### 1. 保存脚本

将脚本保存为 `.js` 文件，例如：

- 路径：`900 Assets/960 Scripts/Dataviewjs/dataview_inline_fields_table.js`
- 脚本：[[dataview_inline_fields_table.js]]

### 2. 在笔记中引用

**模式1：当前笔记的字段**

````
```dataviewjs
await dv.view("900 Assets/960 Scripts/Dataviewjs/dataview_inline_fields_table.js", {mode: "current"})
```
````

**模式2：同文件夹所有笔记的字段**

````
```dataviewjs
await dv.view("900 Assets/960 Scripts/Dataviewjs/dataview_inline_fields_table.js", {mode: "folder"})
```
````

**模式3：指定笔记路径的字段**

````
```dataviewjs
// 同一文件夹的笔记
await dv.view("900 Assets/960 Scripts/Dataviewjs/dataview_inline_fields_table.js", {
  mode: "path",
  path: "目标笔记.md"
})

// 跨文件夹引用
await dv.view("900 Assets/960 Scripts/Dataviewjs/dataview_inline_fields_table.js", {
  mode: "path",
  path: "100 Projects/PJ-2026羽乒比赛.md"
})
```
````

## 功能特点

### 当前笔记模式 (current)

- 提取当前笔记中所有 `[字段名::值]` 格式的内联字段
- 按字段分组，生成表格
- 支持百分比进度条渲染

**示例：** 笔记内容：

```markdown
- [项目::网站重构]
- [状态::进行中]
- [进度::75%]
- [项目::移动应用]
- [状态::已完成]
- [进度::100%]
```

生成表格：

|项目|状态|进度|
|---|---|---|
|网站重构|进行中|75% 进度条|
|移动应用|已完成|100% 进度条|

### 文件夹模式 (folder)

- 扫描同文件夹所有笔记
- 汇总所有内联字段
- 第一列显示笔记链接
- 自动对齐不同笔记的字段

**示例输出：**

| 📝 笔记 | 任务  | 优先级 | 状态  |
| ----- | --- | --- | --- |
| 笔记A   | 设计  | 高   | 完成  |
|       | 开发  | 中   | 进行中 |
| 笔记B   | 测试  | 高   | 待办  |

### 路径模式 (path)

- 指定任意笔记路径，跨文件夹引用
- 显示与当前笔记模式相同的表格格式
- 适用于在汇总文档中引用其他笔记的字段

**示例输出：**

📊 笔记内联字段: 目标笔记

|任务|优先级|状态|
|---|---|---|
|设计|高|完成|
|开发|中|进行中|

## 高级特性

✅ **自动进度条**：识别 `XX%` 格式，自动渲染进度条
✅ **多值字段**：同一字段多个值会分多行显示
✅ **智能对齐**：不同笔记的字段自动对齐
✅ **友好提示**：无数据时显示清晰的提示信息
✅ **统计信息**：folder 模式显示笔记数和字段数
✅ **跨路径引用**：path 模式支持任意路径引用

## 使用场景

| 场景 | 推荐模式 | 代码 |
|------|---------|------|
| 项目文档中显示项目字段 | `current` | `{mode: "current"}` |
| 项目文件夹汇总所有子项目 | `folder` | `{mode: "folder"}` |
| 工作备忘中引用其他项目进度 | `path` | `{mode: "path", path: "xxx.md"}` |
| 跨文件夹引用笔记 | `path` | `{mode: "path", path: "folder/xxx.md"}` |
