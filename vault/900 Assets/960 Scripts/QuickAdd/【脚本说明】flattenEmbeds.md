# SwopEmbeds 脚本使用说明

## 功能概述

将当前笔记中的 `![[嵌入]]` 引用**内联为实际内容**，同时将源笔记中的对应段落**替换为反向嵌入引用**——相当于调换引用方向，内容不动只换指针。

## 适用场景

- 将分散的嵌入内容合并到当前笔记，做成一个完整文档
- 整理知识库时，把内容的"归属地"从源笔记迁移到当前笔记
- 知识重组：内容搬到新位置，旧位置保留指向新位置的引用

## 行为示意

```
── 执行前 ──
📄 当前笔记.md          📄 源笔记.md
  ![[源笔记#标题1]]        # 标题1
                           内容...

── 执行后 ──
📄 当前笔记.md          📄 源笔记.md
  # 标题1                 ![[当前笔记#标题1]]
  内容...
```

## 交互流程

```
光标放在嵌入附近 → 运行命令
         ↓
自动识别光标最近（同行优先）的 ![[嵌入]]
         ↓
┌─ 只有 1 个嵌入 → 直接确认
└─ 多个嵌入 → 选择面板
       ◆ ![[笔记A#标题1]]  (行 5)    ← 光标所在行
       ◇ ![[笔记B]]        (行 12)
       ◇ ![[笔记C#标题2]]  (行 18)
       ──────────────
       ⚡ 全部嵌入（3 个）
         ↓
确认面板（预览双向变更）→ 执行 → 光标跳到替换位置
```

## 支持的嵌入格式

| 格式 | 当前笔记 | 源笔记变更 |
|------|----------|-----------|
| `![[笔记名]]` | 内联全部内容（去 frontmatter） | 替换为 `![[当前笔记]]` |
| `![[笔记名#标题]]` | 内联该标题段落（含子标题） | 该段落替换为 `![[当前笔记#标题]]` |
| `![[笔记名#标题1#标题2]]` | 内联嵌套标题段落 | 仅 `#标题2` 替换为反向引用，`#标题1` 保留 |
| `![[笔记名#标题\|^块ID]]` | 内联标题段落（块 ID 被忽略） | 同上 |

## 安装方法

1. 脚本已位于 `900 Assets/960 Scripts/QuickAdd/swopEmbeds.js`
2. 打开 QuickAdd 插件设置 → ⚙ → **Manage Macros**
3. 点击 **Add Macro** → 命名为 `SwopEmbeds`
4. 在 Macro 中点击 **Add step** → 选择 **User Script** → 选择 `swopEmbeds.js`
5. 可选：在 **Settings → Hotkeys** 中搜索 "QuickAdd: Swop Embeds" 绑定快捷键

## 使用方法

1. 打开包含 `![[嵌入]]` 的笔记
2. 将光标移到目标嵌入附近（同行最佳）
3. 通过 QuickAdd 命令或快捷键运行
4. 在弹出的选择面板中确认要内联的嵌入
5. 执行完成后光标会自动跳到内联内容的位置

## 注意事项

- **双向变更**：当前笔记和源笔记都会被修改，建议确认后再执行
- **同一源笔记多处嵌入**：脚本会累积处理，先提取的段落会在缓存中标记，后续引用不会重复提取
- **自引用嵌入**会被自动跳过
- **frontmatter 处理**：整篇笔记嵌入时自动去除源笔记的 YAML frontmatter
