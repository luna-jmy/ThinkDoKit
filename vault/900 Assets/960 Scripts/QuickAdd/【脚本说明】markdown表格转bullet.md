## 安装步骤

1. **保存脚本**
    - 将脚本保存为 `.js` 文件: [[obsidian_table_to_bullet.js]]
    - 放在 Obsidian vault 文件夹（ `900 Assets/960 Scripts/QuickAdd`）
2. **配置 QuickAdd**
    - 打开 QuickAdd 设置
    - 点击 "Manage Macros" → "Add Macro"
    - 添加 "User Script" → 选择你保存的脚本
    - 回到主界面，添加一个 "Macro" 类型的命令
    - 配置该 Macro 运行你刚创建的脚本
3. **使用**
    - 光标放在表格任意位置
    - 执行你创建的 QuickAdd 命令（可以设置快捷键）

## 功能说明

**三种转换方式示例：**

原表格：

```
| 水果 | 颜色 | 价格 |
| --- | --- | --- |
| 苹果 | 红色 | $2 |
| 香蕉 | 黄色 | $1 |
```

**方式1（按行转）：**

```
- 水果：苹果
- 颜色：红色
- 价格：$2
- 水果：香蕉
- 颜色：黄色
- 价格：$1
```

**方式2（按列转）：**

```
- 水果
  - 苹果
  - 香蕉
- 颜色
  - 红色
  - 黄色
- 价格
  - $2
  - $1
```

**方式3（第一列为主项）：**

```
- 苹果
  - 颜色：红色
  - 价格：$2
- 香蕉
  - 颜色：黄色
  - 价格：$1
```

脚本会自动识别光标位置的表格。
