# metadata2tag.js 脚本使用说明

## 功能概述
metadata2tag.js 是一个 QuickAdd 自定义宏脚本，用于将 Obsidian 笔记中的元数据格式 `[key::value]` 转换为标签格式 `#key/value`。这个脚本可以批量处理笔记中的元数据，将其转换为更容易组织和检索的标签结构。

## 使用前提
- 已安装 QuickAdd 插件
- 已在 QuickAdd 中配置了自定义宏并加载此脚本

## 使用方法
1. 打开需要转换元数据的笔记文件
2. 通过 QuickAdd 触发此宏
   - 可以通过命令面板 (Ctrl+P) 搜索并运行 QuickAdd 命令
   - 或者通过设置的热键/快捷方式触发
3. 脚本将自动处理当前活动笔记中的所有元数据

## 转换规则
- 识别格式：`[key::value]`
- 转换为：`#key/value`
- 特殊符号处理：自动清理 key 和 value 中的特殊符号（如 @#$%^&*() 等）
- 如果清理后的 key 或 value 为空，则保留原格式不转换

## 示例
### 转换前
```
这是一个笔记示例。
[状态::进行中]
[优先级::高]
[负责人::张三]
[特殊::@#$%]
```

### 转换后
```
这是一个笔记示例。
#状态/进行中
#优先级/高
#负责人/张三
[特殊::@#$%]  // 由于清理后为空，保持原样
```

## 注意事项
1. 脚本仅处理当前活动笔记，不会批量处理多个文件
2. 如果笔记中没有找到可转换的元数据，将显示提示信息
3. 转换操作是不可逆的，建议在重要笔记上使用前先备份
4. 脚本会自动过滤特殊符号，确保生成的标签符合 Obsidian 规范

## 错误处理
- 如果没有打开任何笔记文件，将显示错误提示："请先打开一个笔记文件"
- 如果转换完成但没有找到需要转换的元数据，将显示提示："没有找到需要转换的元数据"
- 转换成功后，将显示提示："元数据转标签完成！"

## 扩展建议
- 如需批量处理多个文件，可以考虑结合其他脚本或插件使用
- 可以根据实际需求修改 `cleanSpecialChars` 函数，调整特殊符号的处理规则
