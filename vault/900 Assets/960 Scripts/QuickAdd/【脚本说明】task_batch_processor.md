# Task Batch Processor脚本使用说明

## 功能概述

`task_batch_processor2.js` 是一个为 Obsidian 设计的 QuickAdd 宏脚本，用于批量处理当前活动文件中的任务。它可以一次性修改多个任务的状态，提高任务管理效率。

## 安装要求

- Obsidian 应用
- QuickAdd 插件已安装并启用

## 安装方法

1. 将 `task_batch_processor2.js` 文件保存到 Obsidian 保险库的某个位置（例如 `Scripts` 文件夹）
2. 在 Obsidian 中打开 QuickAdd 插件设置
3. 点击 "Manage Macros"
4. 创建一个新的宏，并添加 "Execute JS" 命令
5. 在 "File path" 字段中，选择刚刚保存的 `task_batch_processor2.js` 文件
6. 保存宏设置

## 使用方法

1. 打开包含任务的笔记文件
2. 通过 QuickAdd 运行此宏（可以通过命令面板、快捷键或 QuickAdd 菜单）
3. 脚本会自动检测当前文件中的所有任务
4. 从弹出的菜单中选择要执行的操作类型
5. 确认操作（默认为 "y"，直接按 Enter 即可确认）
6. 脚本会批量处理所有符合条件的任务，并显示处理结果

## 支持的操作

脚本支持以下五种批量操作：

1. **标记完成** ✅
   - 将所有任务状态改为 `[x]`
   - 适用于：已完成所有任务

2. **标记取消** ❌
   - 将所有任务状态改为 `[-]`
   - 适用于：取消所有任务

3. **标记推迟** ⏭️
   - 将所有任务状态改为 `[>]`
   - 适用于：推迟所有任务

4. **标记为未完成** ⏹️
   - 将所有任务状态改为 `[/]`
   - 适用于：标记所有任务为未完成状态

5. **重置为待办状态** 🔄
   - 仅将非待办状态的任务改为 `[ ]`
   - 适用于：将已完成、取消或推迟的任务重置为待办状态

## 注意事项

- 脚本仅处理当前活动文件中的任务
- 任务格式必须符合 Obsidian 标准任务格式：`- [ ] 任务内容`
- 脚本会保留任务的原始缩进
- 操作前会显示确认提示，默认为确认（按 Enter 即可）
- 可以通过输入 "n" 或 "no" 取消操作

## 错误处理

如果出现以下情况，脚本会显示相应的通知并终止执行：

- 没有打开的文件
- 当前文件中没有任务
- 没有符合条件的任务需要处理
- 用户取消了操作

## 示例

假设有以下任务列表：

```markdown
- [ ] 待办任务 1
- [x] 已完成任务
- [-] 已取消任务
- [>] 推迟任务
- [ ] 待办任务 2
```

选择 "重置为待办状态" 操作后，结果将是：

```markdown
- [ ] 待办任务 1
- [ ] 已完成任务
- [ ] 已取消任务
- [ ] 推迟任务
- [ ] 待办任务 2
```

## 自定义修改

如需修改脚本行为，可以编辑以下部分：

- `taskPattern` 变量：修改任务识别的正则表达式
- `actions` 数组：添加或修改操作类型
- `getTaskMarker` 函数：修改不同操作对应的任务状态标记
- `getActionDescription` 函数：修改操作描述文本
