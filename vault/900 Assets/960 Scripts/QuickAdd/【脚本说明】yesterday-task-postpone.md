# yesterday-tasks-postpone.js 脚本说明文档

## 概述
`yesterday-tasks-undo.js` 是一个用于 Obsidian 的 Templater 脚本，主要功能是从前一天的日记文件中提取未完成的任务，并将这些任务插入到当前日记文件的光标位置，同时在前一天的日记文件中将这些任务标记为已推迟。

## 功能特点
- 自动识别当前日记文件中的日期
- 获取前一天日记文件的路径
- 从前一天的日记中提取所有未完成的任务
- 将未完成的任务插入到当前文件的光标位置
- 在前一天的日记文件中将这些任务标记为已推迟（从 `- [ ]` 变为 `- [>]`）
- 提供操作反馈，告知用户移动了多少任务

## 使用方法
1. 将此脚本保存到 Obsidian 的 Templater 脚本文件夹中
2. 在日记模板中添加以下代码来调用此脚本：
   ```javascript
   <%*
   const yesterdayTasks = await tp.user.yesterday_tasks_undo();
   tR += yesterdayTasks;
   %>
   ```
3. 创建新日记时，脚本会自动执行，将前一天的未完成任务插入到当前文件中

## 文件路径要求
脚本假设日记文件存储在以下路径结构中：
```
500 Journal/540 Daily/YYYY-MM-DD.md
```
如果您的日记文件存储在不同的路径，请修改 `getDailyNotePath` 函数中的路径格式。

## 函数说明

### getDailyNotePath(dateStr)
- **功能**：根据日期字符串生成日记文件的完整路径
- **参数**：
  - `dateStr`：日期字符串，格式为 "YYYY-MM-DD"
- **返回值**：日记文件的完整路径字符串

### getPreviousDay(dateStr)
- **功能**：计算给定日期的前一天日期
- **参数**：
  - `dateStr`：日期字符串，格式为 "YYYY-MM-DD"
- **返回值**：前一天的日期字符串，格式为 "YYYY-MM-DD"

### extractDateFromFilename(filename)
- **功能**：从文件名中提取日期
- **参数**：
  - `filename`：文件名字符串
- **返回值**：提取的日期字符串，格式为 "YYYY-MM-DD"，如果无法提取则返回当前日期

### readFileContent(filePath)
- **功能**：读取指定文件的内容
- **参数**：
  - `filePath`：文件路径字符串
- **返回值**：文件内容字符串，如果文件不存在或读取失败则返回空字符串

### extractUnfinishedTasks(content)
- **功能**：从文件内容中提取所有未完成的任务
- **参数**：
  - `content`：文件内容字符串
- **返回值**：未完成任务数组，每个元素是一个任务行字符串

### insertTasksAtCursor(tasks)
- **功能**：准备要插入到光标位置的任务文本
- **参数**：
  - `tasks`：任务数组
- **返回值**：格式化后的任务文本，准备插入到光标位置

### markTasksAsForwarded(previousFilePath, tasks)
- **功能**：在前一天的日记文件中将指定的任务标记为已推迟
- **参数**：
  - `previousFilePath`：前一天日记文件的路径
  - `tasks`：要标记的任务数组
- **返回值**：无

### moveUndo()
- **功能**：主函数，协调整个任务迁移流程
- **参数**：无
- **返回值**：操作结果消息，包含移动的任务数量和状态信息

## 注意事项
1. 脚本假设日记文件名格式为 "YYYY-MM-DD.md"
2. 脚本假设未完成的任务以 "- [ ]" 开头
3. 推迟的任务会以 "- [>]" 标记
4. 如果前一天没有未完成的任务，脚本会显示相应的提示信息
5. 脚本需要 Templater 插件支持

## 错误处理
脚本包含基本的错误处理机制：
- 如果文件不存在或无法读取，脚本会继续执行而不会中断
- 如果当前没有打开的文件，脚本会返回错误信息
- 所有可能导致脚本中断的错误都被捕获并静默处理

## 示例输出
如果有未完成的任务，脚本会在当前文件中插入如下内容：
```markdown
## 昨日未完成任务
- [ ] 任务1
- [ ] 任务2

_已将2个未完成的任务从2023-11-01移动到当前位置，并在前一日文件中标记为已推迟。_
```

如果没有未完成的任务，脚本会插入：
```markdown
_2023-11-01没有未完成的任务需要移动。_
```
