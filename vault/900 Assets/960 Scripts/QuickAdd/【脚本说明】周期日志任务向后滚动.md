# 整合版说明
支持日记、周记、月记和年记的任务滚动功能。我已经成功将两个文件合并成一个统一的任务滚动脚本。合并后的代码具有以下特点：

## 功能特点

- 支持四种不同类型的笔记：日记、周记、月记和年记
- 自动识别笔记类型并计算上一周期
- 提取未完成任务（`[ ]`）和推迟任务（`[>]`）
- 将任务插入到当前笔记的光标位置
- 从原笔记中删除已迁移的任务
- 自动清理多余空行

## 安装与配置

### 前提条件

- 已安装 Obsidian
- 已安装 QuickAdd 插件

### 安装步骤

1. 将 `unified_tasks_rolling.js` 文件保存到 Obsidian 保险库中的某个位置（例如 `Scripts` 文件夹）
2. 打开 Obsidian 设置，进入 QuickAdd 插件配置
3. 点击 "Manage Macros"，创建一个新宏
4. 为宏添加一个 "JavaScript" 类型的命令
5. 选择刚才保存的 `unified_tasks_rolling.js` 文件
6. 保存宏配置

### 文件夹结构要求

脚本假设您的笔记按以下结构组织：

```
500 Journal/
├── 510 Annual/          (年记，格式：YYYY.md)
├── 520 Monthly/         (月记，格式：YYYY-MM.md)
├── 530 Weekly/          (周记，格式：YYYY-W[w].md)
└── 540 Daily/           (日记，格式：YYYY-MM-DD.md)
```

如果您的文件夹结构不同，请修改脚本中的 `getNotePath` 函数。

## 使用方法

1. 打开一个日记、周记、月记或年记文件
2. 将光标放置在您希望插入任务的位置
3. 通过 QuickAdd 命令、快捷键或按钮运行该宏
4. 脚本将自动从上一周期的笔记中提取未完成任务，并插入到当前笔记中

## 支持的文件名格式

- **日记**: `YYYY-MM-DD.md`（例如：`2025-09-03.md`）
- **周记**: `YYYY-W[w].md`（例如：`2025-W9.md` 或 `2025-W09.md`）
- **月记**: `YYYY-MM.md`（例如：`2025-09.md`）
- **年记**: `YYYY.md`（例如：`2025.md`）

## 任务格式

脚本识别以下格式的任务：

```
- [ ] 未完成任务
- [>] 推迟任务
```

## 输出示例

在日记中运行脚本后，插入的内容可能如下：

```
### 🔄 Rollover Todos
- [ ] 完成项目报告
- [>] 准备会议材料
```

在周记、月记或年记中运行脚本，标题将包含来源周期的名称，例如：

```
### 🔄 Rollover Todos from 2025-W8
- [ ] 完成项目报告
- [>] 准备会议材料
```

## 错误处理

脚本包含基本的错误处理，遇到问题时会显示通知：

- 如果没有打开笔记文件，会提示："错误：请先打开一个笔记文件"
- 如果文件名格式无法识别，会提示："错误：无法识别文件名格式..."
- 如果找不到上一周期的文件，会提示："找不到[上一周期名称]的文件：[文件路径]"
- 如果执行过程中发生其他错误，会提示："执行任务迁移时发生错误，请检查控制台日志"

## 自定义与扩展

如果需要修改脚本以满足您的特定需求，可以关注以下几个函数：

- `getNotePath(dateStr, type)`: 修改文件路径生成逻辑
- `extractUnfinishedTasks(content)`: 修改任务提取逻辑
- `insertTasksAtCursor(tasks, periodInfo)`: 修改任务插入格式

## 注意事项

1. 确保您的笔记文件名符合支持的格式
2. 确保上一周期的笔记文件存在
3. 脚本会直接修改源文件（删除已迁移的任务），请确保您了解这一行为
4. 建议在使用前备份重要笔记

## 常见问题

**Q: 脚本找不到我的上一周期笔记文件？**
A: 请检查您的文件夹结构是否与脚本中定义的一致，或者修改 `getNotePath` 函数以匹配您的实际文件夹结构。

**Q: 我想迁移所有任务，而不仅仅是未完成的任务？**
A: 修改 `extractUnfinishedTasks` 函数中的正则表达式，将 `/- \[( |>)\] .*?\n/g` 改为 `/- \[.\] .*?\n/g`。

**Q: 我想保留原文件中的任务，而不是删除它们？**
A: 注释掉或删除 `deleteTransferredTasks` 函数的调用部分。
