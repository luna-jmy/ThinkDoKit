这个脚本会归档当前文件夹所有笔记的附件。
[[obsidian_archive_attachments.js]]

## 功能特点

**自动识别附件：**

- 支持 `![[图片.png]]` 格式
- 支持 `![](图片.png)` 格式
- 自动解析附件路径

**智能处理：**

- 自动创建 `assets` 文件夹（如果不存在）
- 排除已在 assets 文件夹的附件
- 处理同名文件冲突（自动添加序号）
- Obsidian 会自动更新所有笔记中的链接路径

**安全机制：**

- 移动前显示附件列表供确认
- 显示找不到的附件（可能是外部链接或已删除）
- 详细的错误报告

## 使用场景

假设你的文件夹结构是：

```
📁 项目笔记/
  📄 笔记1.md (引用了 图片A.png)
  📄 笔记2.md (引用了 图片B.jpg)
  🖼️ 图片A.png
  🖼️ 图片B.jpg
```

运行脚本后：

```
📁 项目笔记/
  📄 笔记1.md (链接自动更新为 assets/图片A.png)
  📄 笔记2.md (链接自动更新为 assets/图片B.jpg)
  📁 assets/
    🖼️ 图片A.png
    🖼️ 图片B.jpg
```

## 支持的附件类型

- 图片：png, jpg, jpeg, gif, svg, webp
- 视频：mp4, webm, ogv
- 音频：mp3, wav, m4a, ogg
- PDF 文档
- 其他任何在笔记中引用的文件
